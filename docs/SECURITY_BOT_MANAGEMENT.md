# Security & Bot Management

## Overview

How the site handles bot and probe traffic before it reaches application routes, and how that keeps logs and error tracking quiet.

## Request proxy (`proxy.ts`)

Next.js 16 runs `proxy.ts` (formerly `middleware.ts`) before routing. Its matcher skips `api/`, `_next/static`, `_next/image`, `opengraph-image`, the Sentry tunnel (`/monitoring`), and real static-asset extensions (images, fonts, CSS/JS, `.xml`, `.txt`, `.json`, `.pdf`, media). Everything else passes through it, including dotted probe paths such as `.php`, `.env` or `.bak`.

For each request, in order:

1. **`/cv/download`** passes through untouched. It is a locale-less route handler serving the English CV PDF.
2. **Probe blocking:** an empty **404** is returned when the path starts with an entry in `SUSPICIOUS_PATTERNS` or matches `SUSPICIOUS_EXTENSION_RE`:
   - Prefixes: WordPress (`/wp-login.php`, `/wp-admin`, `/wp-content`, `/wp-includes`, `/wp-json`, `/wordpress`, `/xmlrpc.php`, `/blog/wp-`), secrets and VCS (`/.env`, `/.git`, `/.aws`, `/.ssh`, `/.vscode`), admin panels (`/admin`, `/administrator`, `/phpmyadmin`, `/user/login`, `/manager`, `/console`, `/jenkins`, `/solr`, `/actuator`, `/server-status`, `/_ignition`), CMS paths (`/sites/default`, `/typo3`, `/config.php`, `/cgi-bin`, `/wlwmanifest.xml`, `/sftp-config`), Exchange (`/owa`, `/ecp`), `/api/v1`, and dated blog archives (`/2020/` – `/2024/`).
   - Extensions: `.php`, `.asp(x)`, `.jsp`, `.cgi`, `.env`, `.bak`, `.backup`, `.old`, `.orig`, `.swp`, `.sql`, `.yml`/`.yaml`, `.ini`, `.conf`, `.sh`, `.log`, `.db`, `.sqlite`.
   - `/.well-known/security.txt` is currently in the list too, so it returns 404. Publishing an RFC 9116 `security.txt` is planned and will remove that entry.
3. **Locale-prefixed paths** (`/en`, `/es`, `/en/...`, `/es/...`) continue to the app. The locale is forwarded as the `x-opaso-locale` request header so `app/global-not-found.tsx` can localize 404s ([ADR-0004](./adr/0004-per-locale-root-layout.md)).
4. **Everything else** gets a **307** redirect to `/{locale}{path}`. The locale comes from the `preferred-locale` cookie, then `Accept-Language` (by q-value), then `en`.

**Why 404 rather than 403?** A 404 doesn't confirm that a path exists, and it gives scanners nothing to distinguish this site from any other.

Localized sitemap probes (e.g. `/en/sitemap.xml`) are not redirected: `.xml` is excluded from the matcher, so they 404 like any unknown path. The single sitemap is `/sitemap.xml`.

## robots.txt

Generated by `app/robots.ts`. It allows everything, disallows a few legacy probe paths, and points at `https://opa.so/sitemap.xml`:

```txt
User-Agent: *
Allow: /
Disallow: /wp-admin/
Disallow: /wp-login.php
Disallow: /xmlrpc.php
Disallow: /admin/
Disallow: /.env
Disallow: /.git/

Sitemap: https://opa.so/sitemap.xml
```

`robots.txt` is advisory: well-behaved crawlers honor it, and scanners ignore it. The proxy is the real control.

## Related controls

- **Security headers** (CSP, HSTS, COOP, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`) are set in `next.config.mjs` for production. See [SECURITY_POLICY.md](./SECURITY_POLICY.md).
- **Form abuse:** `/api/contact` requires a Cloudflare Turnstile token and is rate-limited per IP (`lib/rate-limit.ts`). `/api/found-luggage-notify` checks the `Origin` header and is rate-limited too. The rate limiter is in-memory and per instance, so it is best-effort on serverless.
- **Error tracking:** blocked probes never reach a route, so they don't produce Sentry events.

## Verifying

```bash
curl -sI https://opa.so/wp-login.php | head -1
```

Expect `404`. Then:

```bash
curl -sI https://opa.so/cv | grep -i '^location'
```

Expect a redirect to `/en/cv` or `/es/cv`. Unit coverage is in `test/unit/middleware.test.ts`.

## Maintenance

1. Review Vercel logs for new 404 probe patterns and add recurring ones to `SUSPICIOUS_PATTERNS` with a test.
2. Never add a prefix that a real route uses. The tests assert that real pages still route.
3. For volumetric abuse, prefer Vercel Firewall rules over growing the proxy list.
